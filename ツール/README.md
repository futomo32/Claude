# ツール(たまにしか使わないバッチ)

**毎日使うものはトキワ本体のフォルダ(1つ上)に置いてあります。**
ここにあるのは、困った時・調べたい時・機器を試したい時に使うものです。

| 毎日使うもの(1つ上のフォルダ) | 用途 |
|---|---|
| **本番運用で起動.bat** | 営業で使う起動。黒い画面は出ません |
| **トキワ停止.bat** | 上を止める時。画面が無いので閉じて止められません |
| **バックアップ.bat** | 締め時のバックアップ |

## このフォルダの中身

### 更新/
- **トキワ停止して更新.bat** … サーバーを止めて最新版を取り込む(git pull)

### 別の起動のしかた/
| バッチ | 店内共有 | 機器 | 使う場面 |
|---|---|---|---|
| **機器ありで起動.bat** | ✕ | ○ | **原因を画面で見たい時**。エラーが黒い画面にそのまま出る |
| 店内共有で起動.bat | ○ | ✕ | 他端末からの表示確認だけしたい時 |
| トキワ起動.bat | ✕ | ✕ | お試し・練習(DBが無ければサンプルを作る) |

> 本番運用が起動できない時は **機器ありで起動.bat** を使うと、理由が画面に出ます。

### 機器のテスト/
レシート・ドロワー・カード・ロゴの印字を単体で試すもの。

- 機器テスト.bat / レシート桁数テスト.bat
- カードテスト.bat / カード排出.bat / カード書き込みテスト.bat / 券面印字テスト.bat
- ロゴ印字テスト.bat / ロゴ中央寄せテスト.bat / ロゴなしで起動テスト.bat

> **機器テスト.bat はCOMポートを直接叩きます。**店のプリンタはドライバが
> COMを握っているため、**このテストは失敗するのが正常**です(故障ではありません)。
> 詳しくは `docs/hardware-check.md`。

### データの調べもの/
- **台帳の行数しらべ.bat** … 11台帳(xlsx)の行数を数える。**取込のあとの答え合わせ**に使う
- 未取込の列しらべ.bat … 宝飾ナビの列で取り込み漏れが無いか調べる
- 項目さがし.bat … ある値がどの列に入っているかを探す

> **台帳の行数しらべ** は、取り込んだあとに「取りこぼしが無いか」を確かめるものです。
> 出た行数を取込時の件数と見比べます。**顧客・商品・売掛・ポイントは一致するはず**。
> **販売台帳と処方箋はズレて正常**です(販売は伝票と明細に分けている / 処方箋は
> 宝飾品の誤登録を除いている)。行数と列数しか表示しないので実データでも安全です。
> ※このバッチだけ `openpyxl` が要ります(無ければ入れ方を画面に出します)。

## ★このフォルダのバッチを直す時の注意

ここのバッチは `ツール\分類\` の**2階層下**にあるので、**2つ上(トキワ本体)へ
移動してから動きます。**

```
cd /d "%~dp0..\.."
```

**`..` の数を間違えると、`server\` や `db\` を見失って動かなくなります。**
`..` が1つだと `ツール\` 止まりです(2026-09-01 に実際にこの間違いをして直しました)。
ルート直下のバッチは `cd /d "%~dp0"`(..なし)が正しいので、混同しないこと。

新しく足す時・場所を変える時は、**着地点が本当にトキワ本体になるか**を確かめること。
`server\` と `db\` が見えていれば正解です。

また、**`if ( ... )` のブロックの中の `echo` に半角の丸括弧を書かないでください。**
cmd は `echo` の文中の `)` でもブロックの終わりと解釈し、バッチ全体が壊れます
(2026-08-29 に実際に起きた不具合)。
