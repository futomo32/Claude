# ツール(たまにしか使わないバッチ)

**毎日使うものはトキワ本体のフォルダ(1つ上)に置いてあります。**
ここにあるのは、困った時・調べたい時・機器を試したい時に使うものです。

| 毎日使うもの(1つ上のフォルダ) | 用途 |
|---|---|
| **本番運用で起動.bat** | 営業で使う起動。黒い画面は出ません |
| **トキワ停止.bat** | 上を止める時。画面が無いので閉じて止められません |
| **トキワ停止して更新.bat** | サーバーを止めて最新版を取り込む(git pull)。止めるのと更新を1回で済ませます |
| **バックアップ.bat** | 締め時のバックアップ |

## このフォルダの中身

### 別の起動のしかた/
| バッチ | 店内共有 | 機器 | 使う場面 |
|---|---|---|---|
| **機器ありで起動.bat** | ✕ | ○ | **原因を画面で見たい時**。エラーが黒い画面にそのまま出る |
| 店内共有で起動.bat | ○ | ✕ | 他端末からの表示確認だけしたい時 |
| トキワ起動.bat | ✕ | ✕ | お試し・練習(DBが無ければサンプルを作る) |

> 本番運用が起動できない時は **機器ありで起動.bat** を使うと、理由が画面に出ます。

### 機器のテスト/
レシート・ドロワー・カード・ロゴの印字を単体で試すもの。

- 機器テスト.bat / レシート桁数テスト.bat
- カードテスト.bat / カード排出.bat / カード書き込みテスト.bat / 券面印字テスト.bat
- ロゴ印字テスト.bat / ロゴ中央寄せテスト.bat / ロゴなしで起動テスト.bat

> **機器テスト.bat はCOMポートを直接叩きます。**店のプリンタはドライバが
> COMを握っているため、**このテストは失敗するのが正常**です(故障ではありません)。
> 詳しくは `docs/hardware-check.md`。

### 売掛の一括入力/
紙の売掛台帳をExcelに打ち込んで、**まとめて登録する**もの。**番号の順に使います。**

| バッチ | すること |
|---|---|
| **1_入力用ファイルを作る.bat** | `data\real\売掛入力.csv` を作る。Excelで開いて打ち込む |
| **2_下読み_取り込まない.bat** | 件数と**合計金額**を出す。★**紙の合計と突き合わせる** |
| **3_取り込む.bat** | 実際に登録する(バックアップを自動取得、最後に yes が要る) |

> **★2 で合計が紙と合ってから 3 に進んでください。**
> **顧客が1人に決まらない行は取り込みません**(同姓同名に付けると、誰の売掛か
> 分からなくなり取り立て漏れや二重請求になるため)。決まらなかった行は理由付きで
> `data\real\売掛_要確認.csv` に出るので、直してもう一度流します。
> 同じファイルを2回流しても、**二重になる行を警告**します。
> 3 を実行する時は**トキワを止めてから**にしてください。

### Mac用/
**開発環境(Mac)で確かめる時だけ使います。**店のWindowsでは使いません。
Macには `.bat` がないので、ダブルクリックで動く `.command` を置いてあります。

| ファイル | すること |
|---|---|
| **1_仕入先コードを下読み.command** | 仕入先コードを何件入れられるか数える。**書き換えない** |
| **2_仕入先コードを入れる.command** | 実際に入れる(yes の入力が要る。前に自動バックアップ) |
| **トキワ起動.command** | お試し起動＋ブラウザを開く。止める時は Control+C |

> **★Windowsのバッチとは文字コードも改行も逆です。**
> `.bat` は **cp932 + CRLF**、`.command` は **UTF-8 + LF** で保存します。
> CRLFのまま置くとMacで `bad interpreter` になって動きません。
> また `.command` は**実行権限**が要ります(`chmod +x`)。gitには権限ごと記録済みです。
>
> 初回に「開発元を確認できないため開けません」と出たら、ファイルを**右クリック→開く**を
> 選んでください(macOSの安全確認。2回目以降は普通にダブルクリックで開きます)。
> `python3` が無いと言われたら、ターミナルで `xcode-select --install` を実行します。

### データの調べもの/
- **台帳の行数しらべ.bat** … 11台帳(xlsx)の行数を数える。**取込のあとの答え合わせ**に使う
- **台帳の列くらべ.bat** … 台帳にしか無い情報が無いかを調べる。**取りこぼしの確認**
- 未取込の列しらべ.bat … 宝飾ナビの列で取り込み漏れが無いか調べる
- 項目さがし.bat … ある値がどの列に入っているかを探す

> **台帳の行数しらべ** は、取り込んだあとに「取りこぼしが無いか」を確かめるものです。
> 出た行数を取込時の件数と見比べます。**顧客・商品・売掛・ポイントは一致するはず**。
> **販売台帳と処方箋はズレて正常**です(販売は伝票と明細に分けている / 処方箋は
> 宝飾品の誤登録を除いている)。行数と列数しか表示しないので実データでも安全です。
> **台帳の列くらべ** は、**xlsxにしか無い情報が無いか**を確かめるものです。
> トキワの取込元はCSVで、xlsxは使っていません。「CSVの方が情報が多いはず」という
> 前提で進めてきたので、**それを実際に確かめる**ための道具です。
> 列名ではなく**中の値そのもの**で突き合わせます(xlsxは加工済みで、列名だけ比べると
> 見せかけの不一致が大量に出るため)。★に出たものは**漏れの候補**ですが、
> **計算で作った列(経過月・粗利率)と、2つの列を繋げた列(商品キー)は必ず★に出ます**。
> 中身を見て仕分けが要るので、★の一覧はそのまま送ってください。
>
> ※この2つのバッチは `openpyxl` が要ります(無ければ入れ方を画面に出します)。

## ★このフォルダのバッチを直す時の注意

ここのバッチは `ツール\分類\` の**2階層下**にあるので、**2つ上(トキワ本体)へ
移動してから動きます。**

```
cd /d "%~dp0..\.."
```

**`..` の数を間違えると、`server\` や `db\` を見失って動かなくなります。**
`..` が1つだと `ツール\` 止まりです(2026-09-01 に実際にこの間違いをして直しました)。
ルート直下のバッチは `cd /d "%~dp0"`(..なし)が正しいので、混同しないこと。

新しく足す時・場所を変える時は、**着地点が本当にトキワ本体になるか**を確かめること。
`server\` と `db\` が見えていれば正解です。

また、**`if ( ... )` のブロックの中の `echo` に半角の丸括弧を書かないでください。**
cmd は `echo` の文中の `)` でもブロックの終わりと解釈し、バッチ全体が壊れます
(2026-08-29 に実際に起きた不具合)。
