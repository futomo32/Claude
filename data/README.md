# データ置き場

トキワ開発用のデータを置くディレクトリです。

```
data/
└── demo/   … デモデータ(xlsx など)。開発・画面確認用
```

## デモデータの置き方

`data/demo/` に xlsx ファイルをそのままアップロードしてください。
ファイル名は内容が分かる名前を推奨します(例: `顧客.xlsx`, `商品.xlsx`, `売上.xlsx`)。
1つのブックに複数シートが入っていても問題ありません。

## 注意 — 実在のお客様の情報は入れないでください

このリポジトリに置いてよいのは、ダミー化(匿名化)されたデータのみです。
実在のお客様の氏名・住所・電話番号などが入ったデータは、
たとえプライベートリポジトリでも置かないでください。
実データの移行はDB導入時に、リポジトリを経由しない安全な方法で行います。
