# データ置き場

トキワが読むデータを置くディレクトリです。

```
data/
├── real/      … 実データ(.gitignore 済み。GitHubには絶対に載りません)
│   ├── csv/                … 宝飾ナビの生ダンプ(114テーブル)。★本番の取込元
│   ├── xlsx/               … 11台帳。答え合わせ用(取込には使いません)
│   ├── images/             … 商品写真
│   └── 削除商品番号.txt     … 在庫から消す商品番号(1行に1つ)
├── demo_csv/  … デモのCSV(22ファイル)。予行演習用
└── demo/      … デモの11台帳(xlsx)。予行演習用
```

## CSVと xlsx の違い(2026-09-01 整理)

宝飾ナビからは**2つの形**でデータが出てきます。**中身は別物ではなく、CSVの方が詳しい**です。

| | 中身 | 列名 | 役割 |
|---|---|---|---|
| **csv/** | 114テーブルの生ダンプ | `strsyno` `d_user` | **本番の取込はこちら** |
| **xlsx/** | 11台帳(人が読む用のまとめ) | `顧客id` `顧客名` | 答え合わせ用 |

- 取込は `scripts/import_csv.py`。**csv しか読みません**(xlsx は1行も読みません)。
- 中分類・脇石・タグ品名・DM備考などは **CSVにしか入っていません**。
- 11台帳: 顧客 / 家族 / 商品 / 販売 / 売掛 / 売掛履歴 / ポイント /
  ポイントカード履歴 / アプローチ履歴 / メガネ処方箋 / サービスポイント

### xlsx を捨てないでください

xlsx は「コード」と「その名前」が**両方**並んでいるため、**正解表**として使えます。
CSVはコードだけなので、トキワ側で名前に直しています。その答え合わせに要ります
(`scripts/diag_kubun.py` が実際にこれを使って区分コードの対応表を作りました)。

取込のあとの件数チェックにも使います。詳しくは `docs/migration-guide.md`。

### xlsx を直下に置いてしまっても動きます

`data/real/xlsx/` を先に見て、無ければ `data/real/` 直下も見るようにしてあります
(`scripts/_paths.py`)。移し忘れで手が止まらないための保険です。

## 本番の取込手順

```
python scripts\import_csv.py data\real\csv
```

詳しい手順とチェック項目は `docs/go-live-checklist.md` を見てください。

## 注意 — 実在のお客様の情報を GitHub に載せないでください

`data/real/` は `.gitignore` 済みですが、**ここ以外の場所に実データを置かないでください。**
`data/demo/` `data/demo_csv/` に入れてよいのは、ダミー化(匿名化)されたデータだけです。
