# 💰 家族の貸し借りノート

家族のあいだの「誰が・誰に・いつ貸して・いつ返して・いまいくら残っているか」を記録するアプリです。
**おうちのWi-Fi（同じネットワーク）につないだスマホ・タブレット・パソコンから、みんなで同じ記録を見られます。**

## できること

- 💸 **貸した / 🙏 返した** の2種類だけで記録（誰から誰に・金額・日付・メモ）
- 🏠 **残高がひと目でわかる** — 人ごとの「貸している／借りている」と、2人のあいだの差引
- 📄 **1件ずつ追える** — 「9月1日に貸した5,000円 → 9月20日に完済」のように、貸し1件ごとの残りと完済日
  - 返したお金は**古い貸しから順に自動であてる**ので、どの返済がどの貸しに効いたかも出ます
  - まとめて多めに返したときは「前払い」として次の貸しに自動であたります
- 📖 履歴の絞り込み（人・種類・月）、記録の修正・削除
- 📲 同じWi-Fiのスマホから同時に使えて、**数秒で自動的に反映**
- 📄 CSV書き出し（Excelでそのまま開けます）・バックアップ保存
- 🔒 **パソコンが止まっているときは記録できません**（見るだけになります）
  - 端末ごとにバラバラの記録ができて迷子にならないよう、わざとそうしています
  - パソコンを起動すると自動でつながり、また記録できるようになります

## 使いはじめ（パソコン側で1回だけ）

1. パソコンに [Node.js](https://nodejs.org/ja) を入れます（v18以上）
2. このフォルダで、次のどちらかを実行します
   - Mac: `start-mac.command` をダブルクリック
   - Windows: `start-windows.bat` をダブルクリック
   - ターミナルから: `node server.js`
3. こんな表示が出ます。**「同じWi-Fiのスマホ」のURL**を家族に伝えてください

```
  💰 家族の貸し借りノート を開きました

  このパソコンから  : http://localhost:3000/
  同じWi-Fiのスマホ : http://192.168.1.23:3000/
```

4. スマホのブラウザでそのURLを開き、「ホーム画面に追加」しておくとアプリのように使えます
5. まず **⚙️ 設定 → 家族のメンバー** で、家族の名前を追加してください

> サーバーを動かしているパソコンの電源が入っていて、同じWi-Fiにいるあいだ使えます。
> 終わるときはウィンドウで `Ctrl + C`。

### 🪟 Windowsで動かすとき

Windowsのパソコンでも、Macとまったく同じように使えます（`start-windows.bat` をダブルクリック）。
ただし**初回だけ、ファイアウォールの許可**が必要です。ここを許可しないと、スマホから開けません。

1. `start-windows.bat` をダブルクリックする
2. 「**Windows セキュリティの重要な警告**」が出たら、
   **「プライベート ネットワーク」にチェック**を入れて「**アクセスを許可する**」を押す
   - パブリック ネットワークのチェックは入れなくて大丈夫です
3. 黒い画面にURLが出たら準備完了です

#### うっかり「キャンセル」を押してしまったら

管理者として実行したコマンドプロンプト（またはPowerShell）で、次の1行を実行すれば許可できます。

```
netsh advfirewall firewall add rule name="Kashikari 3000" dir=in action=allow protocol=TCP localport=3000
```

#### それでもスマホから開けないとき

Wi-Fiの設定が「パブリック ネットワーク」になっていると、Windowsがスマホからの通信を遮断します。
**設定 → ネットワークとインターネット → Wi-Fi → （つないでいるWi-Fi名）** を開き、
ネットワーク プロファイルを「**プライベート**」にしてください。

#### スリープに注意

パソコンがスリープするとサーバーも止まります。よく使う時間帯だけ
**設定 → システム → 電源** でスリープしないようにしておくと快適です（Macも同じです）。

### 🖥 MacとWindowsのどちらで動かす？

- **どちらでもかまいませんが、動かすのは1台だけ**にしてください。2台で動かすと記録が別々になります
- あとから別のパソコンに引っ越すときは、**`data.json` をコピーして**新しいパソコンの `kashikari` フォルダに置けば、記録もそのまま移せます
- Macの場合も初回に「ネットワーク上の接続を許可しますか？」と出るので「許可」を押してください

### ポートを変えたいとき

`3000` がすでに使われている場合は、番号を変えて起動します。

```sh
PORT=8080 node server.js          # Mac / Linux
set PORT=8080 && node server.js   # Windows
```

## データについて

- 記録はサーバーを動かしているパソコンの **`data.json`** に保存されます（外部には送信しません）
- 記録の置き場所はここ1か所だけです。スマホの中には残らないので、記録が二重になったり迷子になったりしません
- このファイルをときどきコピーしておくか、**設定 → バックアップ保存** をしておくと安心です
- `data.json` は Git に入らないようにしてあります（家族のお金の記録なので）

## つながらないときは

| こまりごと | 見るところ |
|---|---|
| スマホでURLを開けない | スマホとパソコンが**同じWi-Fi**につながっているか。会社や学校のWi-Fiだと、端末どうしの通信が禁止されていることがあります |
| Windowsでスマホから開けない | ファイアウォールの許可と、Wi-Fiの「プライベート」設定。上の「🪟 Windowsで動かすとき」を見てください |
| `ポート 3000 はすでに使われています` と出る | 上の「ポートを変えたいとき」を試してください |
| 「⚠️ つながっていません」と出て記録できない | パソコン側でサーバーが動いていません。起動すると自動でもどります（「🔄 もう一度つなぐ」を押すとすぐ確かめられます）|
| パソコンのIPアドレスが変わった | Wi-Fiルーターを再起動すると変わることがあります。起動時に表示されるURLをもう一度確認してください |

## ファイル構成

| ファイル | 役割 |
|---|---|
| `server.js` | サーバー本体（Node.jsの標準機能だけ。`npm install` 不要） |
| `public/index.html` | 画面とデザイン |
| `public/app.js` | 残高の計算・画面の動き |
| `public/manifest.json` / `public/icon.svg` | ホーム画面追加用（PWA） |
| `data.json` | 記録の保存先（起動すると自動で作られます） |

## 安全のためのおことわり

家庭内の信頼できるネットワークで使う前提のため、合言葉（パスワード）はありません。
同じWi-Fiにつないだ人なら誰でも開けるので、**公共のWi-Fiや、来客の多いネットワークでは動かさないでください**。
