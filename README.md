# Claude リポジトリ

このリポジトリでは3つのWebアプリを公開しています。どれもサーバー不要・インストール不要で、スマホのブラウザだけで動きます。

| アプリ | 公開URL | フォルダ |
|---|---|---|
| ⏰ ヤナセぱっと勤怠 | `https://futomo32.github.io/Claude/` | リポジトリ直下 |
| 📚 中学5教科マスター | `https://futomo32.github.io/Claude/english/` | `english/` |
| ✨ プロンプトメーカー | `https://futomo32.github.io/Claude/prompt/` | `prompt/` |

> **GitHub Pages の設定**: Settings → Pages で **Branch: `main` / フォルダ: `/(root)`** を選んでください。
> この設定ひとつで、上の3つのURLが同時に配信されます。
> （直下に勤怠アプリの `index.html` があるため、配布済みのルートURLはそのまま使えます）

## ⏰ ヤナセぱっと勤怠

パート・アルバイトのスタッフ向けの、スマホで使える勤怠記録アプリです。

### できること

- 🌞 **出勤** / ☕ **休憩スタート** / 💪 **休憩おわり** / 🌙 **退勤** — ボタンを押すだけで今の時刻を記録
- ✍️ 記録した時間はタップして手動修正OK（休憩は複数回に対応）
- 📅 月ごとの履歴表示（出勤日数・合計勤務時間を自動集計）
- 💰 時給を設定すると、その月の給料のめやすを表示
- 📄 月の記録をCSVでダウンロード（Excelでそのまま開けます）
- 📲 「ホーム画面に追加」でアプリのように使える（PWA・オフライン対応）

### データについて

- 記録はスマホ（ブラウザ）の中だけに保存され、サーバーには送信しません
- ブラウザのデータを消すと記録も消えるため、**月末にCSVを保存**しておくのがおすすめです
- 1台のスマホ＝1人分の記録です（スタッフごとに各自のスマホで使ってください）

### ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（HTML/CSS/JSすべて入り） |
| `guide.html` | 使い方ガイド |
| `manifest.json` | ホーム画面追加用の設定（PWA） |
| `sw.js` | オフライン対応（Service Worker） |
| `icon.png` / `icon-maskable.png` / `logo.png` | アイコン・ロゴ |

## 📚 中学5教科マスター（`english/`）

塾の授業・自習用に作った、中学生向けの5教科学習アプリです。

### 使い方

1. アプリを開くと教科メニュー（国語・数学・英語・理科・社会）が表示される
2. 教科を選ぶと10段階のレベル選択画面へ
3. レベルを選ぶと30問のクイズが出題される
4. 答えるとすぐに ⭕/❌ と解説が表示される
5. 結果画面でまちがえた問題をまとめて復習できる

### レベル構成（全教科 10段階 × 各30問 = 300問 / 合計1,500問）

学年順に積み上がる構成で、Lv1〜3が中1、Lv4〜6が中2、Lv7〜9が中3、Lv10が高校受験の総仕上げです。

| Lv | 国語 | 数学 | 英語 | 理科 | 社会 |
|----|------|------|------|------|------|
| 1 | 漢字の読み書き | 正負の数 | be動詞・基本単語 | 植物のつくりと分類 | 世界の地理 |
| 2 | 語句と熟語 | 文字式と一次方程式 | 一般動詞・疑問詞 | 身のまわりの物質 | 日本の地理① |
| 3 | 文法の基礎 | 比例・反比例と図形 | 名詞・命令文・can | 光・音・力と大地 | 日本の地理② |
| 4 | 品詞と活用 | 連立方程式 | 過去形 | 化学変化と原子・分子 | 歴史① 古代 |
| 5 | 敬語・慣用句 | 一次関数 | 未来と助動詞 | 電流と磁界 | 歴史② 中世 |
| 6 | 説明文の読解 | 図形の性質と確率 | 不定詞と動名詞 | からだのつくりと天気 | 歴史③ 近世 |
| 7 | 小説・随筆の読解 | 展開・因数分解・平方根 | 比較 | 運動とエネルギー | 歴史④ 近代 |
| 8 | 古文の基礎 | 二次方程式 | 受け身と現在完了 | 化学変化とイオン | 歴史⑤ 現代 |
| 9 | 漢文と詩歌 | 関数y=ax²・相似・円 | 関係代名詞・分詞 | 生命の連続性と宇宙 | 公民① 憲法と政治 |
| 10 | 受験 総仕上げ | 受験 総仕上げ | 受験 総仕上げ | 受験 総仕上げ | 受験 総仕上げ |

### 特長

- 📱 スマホ最適化（タップ操作・レスポンシブ）
- 🔀 出題順・選択肢は毎回シャッフル
- 📝 全問に日本語の解説つき
- 🖼 図が必要な問題には図版を表示（計183点：数学68・理科62・社会53）
  - 関数のグラフ、円周角、立体、回路図、天体の位置、雨温図、三権分立の図など
- 🏆 教科・レベルごとのベストスコアを端末に保存（localStorage）
- 🔒 データは端末内のみで完結（サーバー送信なし・他の生徒からは見えない）

### 問題の追加・編集

問題データは `english/data/` に教科ごとに置いてあります。編集したら次のコマンドで `index.html` を作り直します。

```bash
node english/build.js
```

build.js は生成前に、各レベルが30問あるか・選択肢が4つで重複していないか・図に不正なコードが混じっていないかを検査し、問題があれば生成を中止します。

問題1件の書き方:

```js
{t:"分類ラベル", q:"問題文（空所は ___）", c:["正解","誤答1","誤答2","誤答3"], a:0, e:"解説文"}
```

`c` の先頭に正解を書き、`a:0` のままにしてください（表示時に自動でシャッフルされます）。
図を付けたい場合は `fig:"<svg viewBox='0 0 240 160'>…</svg>"` を追加します。

## ✨ プロンプトメーカー（`prompt/`）

「AIにうまく頼めない」を解決するアプリです。やりたいことを選んで質問に答えると、
**ChatGPT や Claude にそのまま貼れる指示文（プロンプト）** ができあがります。

### 使い方

1. やりたいこと（画像／分析／スライド／文章…）を選ぶ
2. 出てくる質問に答える（5〜9問・「とばす」もOK）
3. できたプロンプトを **コピー** して、おすすめのAIに貼る

### 2つの出力モード

| モード | どんなとき | 出てくるもの |
|---|---|---|
| 📋 **そのまま使う** | やりたいことが決まっている | 役割・条件・出力形式まで整った指示文。貼れば完成 |
| 💬 **AIに深掘りしてもらう** | イメージがぼんやりしている | AIが選択肢つきで質問してきて、最後に完成プロンプトを出してくれる指示文 |

例）画像をつくりたい → 用途・画風・雰囲気・構図・比率・NG要素を聞かれる → 
「まず1枚出して、そのあと使ったプロンプトも日英で見せて」まで含んだ指示文ができる。

### 用意しているカテゴリ（14種）

| カテゴリ | 何ができるか |
|---|---|
| 🎨 画像 | 用途・画風・構図・比率・NG要素まで指定した画像プロンプト |
| 🎥 AIで動画 | Higgsfield・Sora などに貼る**英語プロンプト**を作らせる指示文（カメラワーク・光・比率つき） |
| 🎬 動画の台本 | ショート動画〜YouTube。冒頭3秒のフック、話し言葉、構成表・テロップまで |
| 📈 表・データ分析 | Excel/CSVを渡して傾向・比較・原因・アクションを出させる |
| 📊 スライド・パワポ | 構成案→本文。Marp/HTMLスライドの出力にも対応 |
| ✍️ 文章 | メール・お知らせ・記事・SNS・おわび文など |
| 💌 DM・お客さま案内 | はがき／A4チラシ／三つ折り／**冊子（A4・見開きA3）**／メール／LINE／SNSのDM。紙モノは紙面のパーツ・ページごとに出力 |
| 🍰 メニュー・POP | キャッチコピー・商品説明・値段の見せ方。景表法まわりの歯止めつき |
| 📝 要約・議事録 | 決定事項とToDo（担当・期限）まで |
| 🌍 翻訳・英語 | 訳文＋直訳＋変更理由。英文添削にも |
| 💡 アイデア出し・相談 | 制約つきで実行できる案を。リスク指摘も |
| ⚙️ 自動化・コード | Excel関数・GAS・Python。初心者向けの手順つき |
| 📚 調べる・学ぶ | 自分のレベルに合わせた深さで |
| 🧩 その他 | 当てはまるものがないとき |

### 特長

- 🤖 **AIごとの得意分野つき** — 「これは Claude、これは ChatGPT」を理由つきで表示
- 🧂 **仕上げの味つけ** — 「結論から」「表にまとめて」「3案出して」などをタップで追加
- 💡 **うまくいくコツ** — カテゴリごとの実践的な注意点（個人情報を消す、など）
- 🕘 **履歴** — 前につくったプロンプトを開き直して再利用できる
- 🔒 **通信ゼロ** — APIキー不要。入力も履歴も端末内（localStorage）だけに保存

### ファイル構成

| ファイル | 役割 |
|---|---|
| `prompt/index.html` | 画面（HTML/CSS） |
| `prompt/data.js` | カテゴリ・質問・プロンプトの組み立てルール |
| `prompt/app.js` | 画面の動き（質問の進行・コピー・履歴） |
| `prompt/manifest.json` | ホーム画面追加用の設定（PWA） |

### 質問やカテゴリを増やしたいとき

`prompt/data.js` の `CATEGORIES` に1件足すだけです。

```js
{
  id: "video", goal: "動画の台本をつくってもらう", icon: "🎬",
  title: "動画の台本をつくりたい", desc: "YouTube・研修動画",
  tools: [{ name: "Claude", why: "長い台本でも話の筋が通る" }],
  tips: ["最初の5秒で結論を言わせると離脱が減ります"],
  questions: [
    { id: "theme", q: "何の動画ですか？", type: "textarea", ph: "例：新人向けのレジ操作の説明" },
    { id: "len", q: "長さは？", type: "choice", opts: [
      { v: "1", l: "1分", p: "1分" }, { v: "5", l: "5分", p: "5分" }
    ] }
  ],
  build: (H) => block([
    "あなたは動画構成のプロです。",
    sec("テーマ", H.t("theme")),
    sec("長さ", H.t("len"))
  ])
}
```

- `type` は `choice`（1つ選ぶ）／`multi`（いくつでも）／`text`／`textarea`
- 選択肢の `p` はプロンプトに入る文言（省略すると `l` がそのまま入る）。`p: ""` にすると「おまかせ」＝その項目はプロンプトに出ません
- `optional: true` を付けると「この質問はとばす」が出ます
- `when: (a) => a.media === "book"` を付けると、**特定の答えを選んだときだけ出る質問**になります（例：冊子を選んだときだけページ数を聞く）
- `build` の中では `H.t("id")`（答えの文字列）、`H.list("id")`（配列）、`H.has("id","値")`（判定）が使えます
