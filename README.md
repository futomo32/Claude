# ⏰ ぱっと勤怠

パートさん・アルバイトさん向けの、スマホで使えるかわいい勤怠記録アプリです。
サーバー不要・インストール不要で、ブラウザだけで動きます。

## ✨ できること

- 🌞 **出勤** / ☕ **休憩スタート** / 💪 **休憩おわり** / 🌙 **退勤** —— ボタンを押すだけで今の時刻を記録
- ✍️ 記録した時間はタップして手動修正OK（休憩は複数回に対応）
- 📅 月ごとの履歴表示（出勤日数・合計勤務時間を自動集計）
- 💰 時給を設定すると、その月のお給料のめやすを表示
- 📄 月の記録をCSVでダウンロード（Excelでそのまま開けます）
- 📲 「ホーム画面に追加」でアプリのように使える（PWA・オフライン対応）

## 🚀 使いかた

### いちばん簡単な方法（GitHub Pages）

1. このリポジトリの **Settings → Pages** で、ブランチを選んで公開
2. 表示されたURLをスマホで開く
3. ブラウザのメニューから **「ホーム画面に追加」** をタップ

これでアプリのように使えます。

### ローカルで試す

```bash
# このフォルダで簡易サーバーを起動
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

`index.html` をそのままブラウザで開いても動きます（PWA機能以外）。

## 📝 データについて

- 記録はスマホ（ブラウザ）の中だけに保存されます。サーバーには送信しません
- ブラウザのデータを消すと記録も消えるため、**月末にCSVを保存**しておくのがおすすめです
- 1台のスマホ＝1人分の記録です（スタッフごとに各自のスマホで使ってください）

## 🗂 ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（HTML/CSS/JSすべて入り） |
| `manifest.json` | ホーム画面追加用の設定（PWA） |
| `sw.js` | オフライン対応（Service Worker） |
| `icon.svg` | アプリアイコン |
