# 📘 中学英語マスター

塾の授業・自習用に作った、スマホでできる中学英語学習アプリです。ブラウザで `index.html` を開くだけで動きます（インストール・サーバー不要）。

## 使い方

1. `index.html` をスマホやPCのブラウザで開く
2. レベルを選ぶと10問のクイズが出題される
3. 答えるとすぐに ⭕/❌ と解説が表示される
4. 結果画面でまちがえた問題をまとめて復習できる

GitHub Pages を有効にすれば URL を配るだけで生徒がスマホから使えます。

## レベル構成

| レベル | 対象 | 内容 |
|--------|------|------|
| Lv1 きほん | 中1 | be動詞・一般動詞・疑問詞・単語 |
| Lv2 過去形マスター | 中1〜2 | 規則動詞/不規則動詞の過去形変化・過去の文 |
| Lv3 文法チャレンジ | 中2〜3 | 比較・受け身・現在完了・不定詞・動名詞 |
| Lv4 高校受験対策 | 中3 | 関係代名詞・並べかえ・間接疑問・分詞・入試頻出熟語 |

## 特長

- 📱 スマホ最適化（タップ操作・レスポンシブ）
- 🔀 出題順・選択肢は毎回シャッフル
- 📝 全問に日本語の解説つき
- 🏆 レベルごとのベストスコアを端末に保存（localStorage）
- 依存ライブラリなしの単一HTMLファイル

## 問題の追加・編集

`index.html` 内の `QUESTIONS` オブジェクトに問題を追加できます。

```js
{t:"分類ラベル", q:"問題文（空所は ___）", c:["正解","誤答1","誤答2","誤答3"], a:0, e:"解説文"}
```

`c` の先頭に正解を書き、`a:0` のままにしてください（表示時に自動でシャッフルされます）。
