## ⏰ ヤナセぱっと勤怠

パート・アルバイトのスタッフ向けの、スマホで使える勤怠記録アプリです。

### できること

- 🌞 **出勤** / ☕ **休憩スタート** / 💪 **休憩おわり** / 🌙 **退勤** — ボタンを押すだけで今の時刻を記録
- ✍️ 記録した時間はタップして手動修正OK（休憩は複数回に対応）
- 📅 月ごとの履歴表示（出勤日数・合計勤務時間を自動集計）
- 💰 時給を設定すると、その月の給料のめやすを表示
- 📄 月の記録をCSVでダウンロード（Excelでそのまま開けます）
- 📲 「ホーム画面に追加」でアプリのように使える（PWA・オフライン対応）

### データについて

- 記録はスマホ（ブラウザ）の中だけに保存され、サーバーには送信しません
- ブラウザのデータを消すと記録も消えるため、**月末にCSVを保存**しておくのがおすすめです
- 1台のスマホ＝1人分の記録です（スタッフごとに各自のスマホで使ってください）

### ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（HTML/CSS/JSすべて入り） |
| `guide.html` | 使い方ガイド |
| `manifest.json` | ホーム画面追加用の設定（PWA） |
| `sw.js` | オフライン対応（Service Worker） |
| `icon.png` / `icon-maskable.png` / `logo.png` | アイコン・ロゴ |

## 📚 中学5教科マスター（`english/`）

塾の授業・自習用に作った、中学生向けの5教科学習アプリです。

### 使い方

1. アプリを開くと教科メニュー（国語・数学・英語・理科・社会）が表示される
2. 教科を選ぶと10段階のレベル選択画面へ
3. レベルを選ぶと30問のクイズが出題される
4. 答えるとすぐに ⭕/❌ と解説が表示される
5. 結果画面でまちがえた問題をまとめて復習できる

### 英語のレベル構成（10段階 × 各30問 = 300問）

| レベル | 対象 | 内容 |
|--------|------|------|
| Lv1 | 中1 | be動詞・あいさつ・基本単語 |
| Lv2 | 中1 | 一般動詞・3単現のs・疑問詞 |
| Lv3 | 中1 | 複数形・代名詞・命令文・can・現在進行形 |
| Lv4 | 中2 | 過去形（規則・不規則動詞の変化） |
| Lv5 | 中2 | 未来（will / be going to）・助動詞・接続詞 |
| Lv6 | 中2 | 不定詞・動名詞・文型（SVOO/SVOC） |
| Lv7 | 中3 | 比較級・最上級・as ... as |
| Lv8 | 中3 | 受け身・現在完了 |
| Lv9 | 中3 | 関係代名詞・分詞・間接疑問文 |
| Lv10 | 受験 | 並べかえ・仮定法・熟語・長文・会話表現 |

### 特長

- 📱 スマホ最適化（タップ操作・レスポンシブ）
- 🔀 出題順・選択肢は毎回シャッフル
- 📝 全問に日本語の解説つき
- 🖼 図が必要な問題にはSVGの図版を表示
- 🏆 レベルごとのベストスコアを端末に保存（localStorage）
- 🔒 データは端末内のみで完結（サーバー送信なし・他の生徒からは見えない）

### 問題の追加・編集

`english/index.html` 内の `SUBJECT_DATA` に問題を追加できます。

```js
{t:"分類ラベル", q:"問題文（空所は ___）", c:["正解","誤答1","誤答2","誤答3"], a:0, e:"解説文"}
```

`c` の先頭に正解を書き、`a:0` のままにしてください（表示時に自動でシャッフルされます）。
図を付けたい場合は `fig:"<svg viewBox='0 0 240 160'>…</svg>"` を追加します。
