# 📚 中学5教科マスター

塾の授業・自習用に作った、スマホでできる中学生向け学習アプリです。ブラウザで `english/index.html` を開くだけで動きます（インストール・サーバー不要）。

現在は **英語** が利用可能で、国語・数学・理科・社会は「準備中」表示になっています。

## 使い方

1. アプリを開くと教科メニュー（国語・数学・英語・理科・社会）が表示される
2. 「英語」を選ぶと10段階のレベル選択画面へ
3. レベルを選ぶと30問のクイズが出題される
4. 答えるとすぐに ⭕/❌ と解説が表示される
5. 結果画面でまちがえた問題をまとめて復習できる

GitHub Pages を有効にすれば URL を配るだけで生徒がスマホから使えます。

## 英語のレベル構成（10段階 × 各30問 = 300問）

| レベル | 対象 | 内容 |
|--------|------|------|
| Lv1 | 中1 | be動詞・あいさつ・基本単語 |
| Lv2 | 中1 | 一般動詞・3単現のs・疑問詞 |
| Lv3 | 中1 | 複数形・代名詞・命令文・can・現在進行形 |
| Lv4 | 中2 | 過去形（規則・不規則動詞の変化） |
| Lv5 | 中2 | 未来（will / be going to）・助動詞・接続詞 |
| Lv6 | 中2 | 不定詞・動名詞・文型（SVOO/SVOC） |
| Lv7 | 中3 | 比較級・最上級・as ... as |
| Lv8 | 中3 | 受け身・現在完了 |
| Lv9 | 中3 | 関係代名詞・分詞・間接疑問文 |
| Lv10 | 受験 | 並べかえ・仮定法・熟語・長文・会話表現 |

## 特長

- 📱 スマホ最適化（タップ操作・レスポンシブ）
- 🔀 出題順・選択肢は毎回シャッフル
- 📝 全問に日本語の解説つき
- 🏆 レベルごとのベストスコアを端末に保存（localStorage）
- 🔒 データは端末内のみで完結（サーバー送信なし・他の生徒からは見えない）
- 依存ライブラリなしの単一HTMLファイル

## 問題の追加・編集

`english/index.html` 内の `QUESTIONS` オブジェクトに問題を追加できます。

```js
{t:"分類ラベル", q:"問題文（空所は ___）", c:["正解","誤答1","誤答2","誤答3"], a:0, e:"解説文"}
```

`c` の先頭に正解を書き、`a:0` のままにしてください（表示時に自動でシャッフルされます）。

## 教科の追加

`SUBJECTS` の配列で教科メニューを管理しています。問題を用意したら `ready:false` を `true` に変えると開けるようになります。

```js
{id:"rika", name:"理科", icon:"理", color:"#10b981", desc:"物理・化学・生物・地学", ready:false},
```
