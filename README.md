# トキワ 宝飾店総合管理システム

宝飾ナビ（現行）を置き換える、Windows単機向けの店舗管理システム。
ローカルで動く軽量なWebアプリ（Python標準ライブラリ + ブラウザ）です。

## 本番機でのテスト起動

宝飾ナビは**開いたまま**で問題ありません。トキワは `localhost` だけで動き、
プリンター・ドロワー・カードリーダーは操作しません（機器制御は未実装）。

### かんたん起動（推奨）

`トキワ起動.bat` をダブルクリック。
Python確認 → 初回はサンプルDB作成 → サーバー起動 → ブラウザ自動オープンまで自動。
終了は「トキワ サーバー」ウィンドウを閉じるだけ。

- Python が必要です（未導入なら https://www.python.org/ から。「Add python.exe to PATH」にチェック）
- 終了後に消したいときはフォルダごと削除でOK（宝飾ナビ側には何も残りません）

### 画面だけ見たい（Python不要）

`tokiwa-ui.html` をダブルクリック。埋め込みサンプルデータで操作感を確認できます
（会計・登録はリロードで消えます＝DB保存なし）。

### 手動起動（DB読み書きあり）

```
python scripts\make_sample_data.py   # 初回のみ。サンプルDBを作成（既存DBは上書きされるので注意）
python server\app.py                  # http://localhost:8760/
```

ポートが衝突する場合は `python server\app.py 8761` のように指定。

## 構成

| 場所 | 内容 |
|---|---|
| `tokiwa-ui.html` | 画面（単一HTML。サーバー起動時はDBの内容を埋め込んで配信） |
| `server/` | ローカルAPIサーバー（配信・会計/顧客/処方箋の保存） |
| `scripts/` | サンプルDB生成・実データ移行スクリプト |
| `db/schema.sql` | SQLiteスキーマ（`db/tokiwa.db` は再生成可・Git管理外） |
| `docs/` | 設計書・変更履歴・周辺機器の調査 |

バージョンは画面左上とログイン画面に表示。変更履歴は `docs/CHANGELOG.md`。
