# 当番シフト自動作成アプリ

1日2人の当番を、みんなの出欠から**自動で組む**スマホ向けアプリです。
インストール不要。`index.html` をスマホやPCのブラウザで開くだけで使えます。

## 使い方（3ステップ）

1. **⚙️ 設定** … メンバー（初期で15人入り）・練習の日を用意する
   - 曜日と期間を選んで「日付を作成」すると、対象日がまとめて作れます
2. **✍️ 出欠入力** … 表のマスをタップして、各自の出欠を入れる
   - タップするたび　空 → 🟢 → 🟡 → 🔴　と切り替わります
3. **⚡ 自動作成** … 「自動で組む」を押すと、1日2人の当番が決まります

## 記号のルール

| 記号 | 意味 | 自動作成での扱い |
|---|---|---|
| 🟢 ○ | 出られる | 優先して選ぶ |
| 🟡 △ | 要確認 | 🟢が足りない日だけ候補にする |
| 🔴 × | 出られない | 選ばない |
| ⚫️ | 暫定で決まっている | 固定（動かさない） |

- できるだけ**回数が偏らない**ように、また**連日**を避けて割り振ります。
- 足りない日は「⚠️ 未定」で表示されるので、🟡や出欠を見直して調整できます。

## 「確定」と手直し

- 一覧で名前の右の「未確定／確定」を押すと切り替わります。
- **確定にした人は自動作成で触りません**（決まった人はそのまま）。
- 変更したい人は確定を外せば、⚫️（暫定確定）も含めて組み直せます。
- 日ごとの当番の名前をタップすると、手動で入れ替え・⚫️固定・空にする ができます。

## その他

- 入力内容は**その端末に自動保存**されます（ブラウザのローカル保存）。
- 「📋 結果をコピー」でLINEなどに貼れるテキストにできます。
- 「書き出し／読み込み」で別の端末へデータを移せます。
