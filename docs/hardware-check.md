# 周辺機器の対応状況と本番機での確認手順

正式運用: Windows PC 1台 + USB接続の周辺機器3点。
会計フロー: ポイントカード読み込み(顧客呼び出し) → レジ → ポイントカード書き込み → レシート印字 → ドロワーオープン

## 機器別の調査結果(2026年7月時点)

### ① レシートプリンター: CITIZEN CT-S601 — ◎ 問題なし

- シチズン・システムズ公式のWindowsドライバーが提供されている
- 標準的なESC/POSコマンド対応で、新アプリからの制御は定番の方法で可能
- 背面に**ドロワーキック端子**があり、DLE EOT / GS a / GS r コマンドでドロワー制御が可能

### ② ドロワー: 品番未確認 — ○ おそらく問題なし(要確認1点)

- フローが「レシート印字→ドロワーオープン」なので、ドロワーは
  **プリンター背面のキック端子(RJ-11、電話線様のコネクタ)経由**の可能性が高い
- この場合、ドロワー自体の型番はほぼ問わない(プリンターが面倒を見る)
- **確認事項**: ドロワーから出ているケーブルの差し先が
  「プリンター背面」なら追加作業なし。「PCのUSBポート直挿し」なら型番の特定が必要

### ③ リライトカードリーダー: スター精密 TCP300II — ⚠ 要注意(最重要)

- Windows用ドライバー・OCXドライバー・サンプルコードは提供されている(制御手段は存在する)
- **ただし2023年6月30日でメーカー販売終了、Windows 11 非対応**(メーカー公表)
- Windows 10はすでにMicrosoftのサポートが終了しており(2025年10月)、
  「Win10のまま使い続ける」は店舗PCとしてセキュリティ上おすすめできない
- 制御方式がOCX(ActiveX)という旧世代技術のため、新アプリからは
  小さな中継プログラムを挟む形になる(実現可能だが開発工数が少し増える)

### TCP300IIへの対応方針(3案)

| 案 | 内容 | 備考 |
|---|---|---|
| A | 本番機(Win11)で動くか実機テストし、動けばそのまま使う | 非対応=動かないとは限らない。ただし故障時の代替機がない |
| B | 後継機/他社のリライトカードプリンターに更新 | 費用がかかるが将来も安心 |
| C | カード書き込みを廃止し「残高はDBが正」方式に変更 | ハード依存が消える。ただしカード券面の残高表示がなくなる運用変更 |

推奨: まずAの実機テスト → 動かない/不安が残る場合にBかCを判断。
Cは修理費用ゼロで恒久解決になるため、カード運用の変更が許容できるなら有力。

## 本番機での確認手順(トキワがなくても今できる)

1. **本番PCのWindowsバージョンを確認** — 設定→システム→バージョン情報。
   Windows 10 か 11 かで③の判断が変わるため最初に確認
2. **CT-S601**: シチズン公式サイトからドライバーを入れ、
   Windowsのプリンター設定から「テストページ印刷」→ 印字されればOK
3. **ドロワー**: ケーブルの差し先を確認(プリンター背面 or PC直挿し)。
   プリンター背面なら、ドライバーのプロパティにあるドロワーキック設定で開閉テスト
4. **TCP300II**: スター製品サポートデータベースからWindowsドライバーと
   ユーティリティを取得し、本番機でカードの読み・書き(リライト)をテスト。
   あわせて本体ラベルの**正確な型番**(TCP342II/TCP352IIなど磁気あり/なしの別)を控える
