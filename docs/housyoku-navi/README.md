# 現行システム「宝飾ナビ」資料

次期システム「トキワ」(仮称)の検討にあたり、現行システム「宝飾ナビ」の画面や仕様に関する資料を集約するディレクトリです。

## 構成

```
docs/housyoku-navi/
├── README.md          … このファイル
└── screenshots/       … 現行システムの画面スクリーンショット
```

## スクリーンショットの置き方

`screenshots/` フォルダに画像ファイル(PNG / JPG)を追加してください。

### ファイル名のつけ方(推奨)

「番号_画面名.png」の形式にすると、一覧で業務の流れ順に並びます。

例:

```
01_login.png           … ログイン画面
02_menu.png            … メインメニュー
03_customer_list.png   … 顧客一覧
04_customer_detail.png … 顧客詳細
05_sales_entry.png     … 売上入力
```

日本語ファイル名(例: `03_顧客一覧.png`)でも問題ありません。

### 補足メモがある場合

画面ごとに気になる点(使いにくい箇所、トキワで改善したい点など)があれば、
このREADMEに追記するか、`screenshots/notes.md` を作ってメモしてください。
