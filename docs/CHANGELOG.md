# トキワ 変更履歴

採番規則: 機能追加・画面変更で 0.1 上げ(v0.7→v0.8)、小さな修正は末尾を上げる(v0.8.0→v0.8.1)。
現在のバージョンは画面左上(サイドバーのロゴ下)とログイン画面に表示。
ソースの全履歴はGitHubが保持しているため、このファイルは要約のみ。

| バージョン | 内容 |
|---|---|
| v0.9.4 | 処方箋レイアウト整理: レンズ名・金額・フレーム名・金額を1行に(金額は短く・読取専用)、合計は別。PD・視力を横一列のプルダウンに(PD遠/近=50〜70+手入力、裸眼/矯正は右・左・両を規定リストから選択)。「(両眼)」「(イレギュラー)」表記とPD左右別トグルを廃止 |
| v0.9.3 | 処方箋の金額をレンズ・フレーム・合計(自動計算)に分割。処方箋を後から編集できる「この処方箋を編集」を追加。レジで現金以外(クレジット/PayPay/掛売/分割)を選ぶと預り金額へ請求額を自動セット |
| v0.9.2 | 処方箋: フレーム購入はフレーム名欄へ取り込み(分類でフレーム/レンズ判別)、全度数プルダウンに手入力を追加、右→左コピー・度数クリアのボタン、度数欄の幅を拡大 |
| v0.9.1 | 処方箋のSPH・CYLを「符号(＋/ー)」と「数字」の2プルダウンに分割し選択を軽減。プリズムの斜め(2方向: 例 0.25 UP + 1.0 OUT)入力に対応 |
| v0.9.0 | 処方箋を全面刷新: 度数をプルダウン入力(SPH ±0.25刻み15.00/CYLマイナス基本5.00/AX 5刻み180/PRI・BAS追加/ADD)+SPH・CYLは手入力可、PDは両眼値が基本で左右別も入力可、裸眼・矯正視力を追加、購入データとの紐付け(未紐付けの購入を選択) |
| v0.8.0 | 和暦入力(生年月日=明治〜令和/結婚記念日=昭和〜令和)、郵便番号+住所2段化と住所検索、必須項目を名前・電話・担当者に変更、全角数字の自動半角化、番号なし追加のピッカー化(電池交換/レンズ/宝石修理/メガネ修理/時計修理/手入力)、処方箋の入力画面を新設、会計後に購入履歴へ即時反映されないバグ修正、バージョン表示 |
| v0.7.x | レジ実用POS化(空明細から組立・商品ピッカー・レジから新規顧客)。入力エラーのインライン表示、同姓同名識別(年齢・最終購入日)、担当者名を田中一槻へ変更 |
| v0.6.x | 検証用ペルソナ(メガネ太郎・ポイント花子など7名)とテスト顧客ボタン |
| v0.5.x | 顧客検索の正規化(全角カナあいまい)、新規/編集モーダル、顧客管理の初期非表示 |
| v0.4.x | SQLite実装(スキーマ・移行スクリプト)、ローカルAPIサーバー、会計のDB永続化 |
| v0.3.x | デモデータ組込(顧客5,204件)、処方箋の宝飾品混入の振り分け |
| v0.2.x | お声がけチェック、処方箋一覧+詳細展開、レジ改善(種類未定レンズ・金額編集) |
