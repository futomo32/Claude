# 別の端末(PC・スマホ・iPad)からトキワを使う手順

トキワは1台のPC(サーバー役)で動かし、同じLAN(同じWi-Fi/ルーター)につながった
別の端末のブラウザから使えます。以下は店内での接続手順です。

> 外出先(店の外)からのアクセスは今は不可です。将来クラウド化で対応予定
> (`docs/cloud-plan.md`)。

---

## 前提
- サーバー役にするPCを1台決める(このPCがトキワ本体・データを持ちます)。
- 使いたい端末(別PC・スマホ・iPad)が**同じLAN**につながっていること。

## 手順

### ① サーバー役のPCで「店内共有モード」で起動する
- **正式運用(2026-09-02〜)は `本番運用で起動.bat`** をダブルクリック。
  こちらは**店内共有と機器(レシート・ドロワー・カード)の両方がON**になります。
- 機器を使わない確認だけなら `店内共有で起動.bat`(または `python3 server/app.py lan`)。

| バッチ | 店内共有 | 機器(レシート等) | 使う場面 |
|---|---|---|---|
| **本番運用で起動.bat** | ○ | **○** | **毎日の営業。これを使う** |
| 店内共有で起動.bat | ○ | ✕ | 他端末からの表示確認だけしたい時 |
| 機器ありで起動.bat | ✕ | ○ | このPCだけで機器の確認をする時 |
| トキワ起動.bat | ✕ | ✕ | お試し・練習(サンプルDBを作る) |

★`本番運用で起動.bat` は**サンプルデータを作りません**。DBが無ければ「実データを
取り込んでください」と出て止まります(偽データが本物と混ざる事故を防ぐため)。
- 起動すると画面に次のように表示されます:
  ```
  【店内共有モード】他のPC・スマホ・iPadから下のURLで開けます(同じLAN内):
    http://192.168.x.x:8760/
  ```
  この **`http://192.168.x.x:8760/`** を控えます(数字は環境で変わります)。

### ② URLが分からないときはIPアドレスを調べる
- Windows: スタート → 「cmd」→ `ipconfig` を実行 → **「IPv4 アドレス」**(例 `192.168.1.20`)。
- そのIPで `http://192.168.1.20:8760/` になります。

### ③ 他の端末のブラウザで開く
- 別PC/スマホ/iPad の Safari や Chrome の**アドレス欄**に
  `http://192.168.1.20:8760/` と入力して開く。
- ログイン画面が出たら、自分のユーザーでログイン。

### ④ ブックマーク/ホーム画面に追加(毎回入力しないため)
- **iPad/iPhone(Safari)**: 共有ボタン → 「ホーム画面に追加」。アイコンから一発で開けます。
- **PC**: ブックマークに登録。
- IPアドレスは基本変わりませんが、ルーター再起動などで変わることがあります
  (下の「IPを固定する」参照)。

### ⑤ つながらないとき(Windowsファイアウォール)
- サーバーPCで初回に「アクセスを許可しますか?」が出たら **「アクセスを許可する」**。
- 出ない/つながらない場合は、Windows ファイアウォールで **ポート 8760(python)** を許可。

---

## 使える範囲(権限)
- 各端末で**ログインが必要**です。使える範囲はログインした人の権限で決まります。
  - **管理者** … すべて
  - **社員** … ユーザー管理・担当者マスタ以外
  - **パート** … 原価(下代)・粗利・商品在庫画面・設定は見えない
- **会計(レジ)も他の端末で使えます**(以前の「他PCは閲覧のみ」は廃止しました)。

## バーコードスキャナについて
- **Bluetooth/USBのバーコードスキャナ**(キーボード入力タイプ)は、他の端末でも
  そのまま使えます。棚卸しやレジの検索欄に「ピッ」と読み取ればOK。
- スマホ/iPadの**カメラ**でバーコードを読む機能は、今は使えません(HTTPS化が必要。
  クラウド化のときに対応予定)。

## 注意
- サーバー役のPCは**営業中つけっぱなし**にしてください(このPCが止まると全端末が使えません)。
- 同時に複数端末から使えます(WALモードで書き込みが競合しにくくしています)。

## (任意)IPアドレスを変わりにくくする
- ルーターの設定で「DHCP固定割当」(サーバーPCのMACアドレスに固定IPを割当)を行うと、
  URLが変わらなくなり安心です。設定方法はルーターの機種により異なります。
