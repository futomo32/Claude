# 店外イベント(催事)でトキワを使う手順 ― 案A「見るだけ」

Macを会場に持って行き、**同じWi-Fiにつないだスマホ・iPadからもトキワを開く**ための手順です。

> **★この手順は「案A(見るだけ)」です。**
> **イベント中の会計はMacで打ちません。**売れたものは紙に控えて、
> **店に戻ってから本番機で「過去の日付で登録する」**を使って打ちます。
>
> 理由は「[なぜ会計を打たないのか](#なぜイベント中に会計を打たないのか)」に書きました。
> ここが一番大事なので、当日の担当者にも必ず伝えてください。

---

## 当日までにやること(店で・1回だけ)

### ① Macにトキワ一式を入れる
店のPCの**トキワのフォルダまるごと**をMacにコピーします(USBメモリ等)。
`server/` `db/` `tokiwa-ui.html` `ツール/` などが全部そろっている状態にします。

### ② Macで python3 が使えるか確かめる
ターミナル(アプリケーション → ユーティリティ)を開いて:

```
python3 --version
```

数字(例 `Python 3.9.6`)が出ればOK。「見つかりません」と出たら:

```
xcode-select --install
```

を実行して入れてください(Appleの標準のものです。追加で入れるものはありません)。

### ③ ★店でリハーサルをする(これは必ず)
**当日ぶっつけは危険です。**会場と同じ組み合わせで一度試してください。

1. **iPhoneのインターネット共有(テザリング)をON**にする
2. **Macとスマホの両方**をそのテザリングにつなぐ
3. 下の「当日の手順」のとおりに起動して、**スマホで実際に顧客が開けるか**を確かめる

> ⚠ **機種・契約によっては、テザリングにつないだ端末どうしが通信できないことがあります。**
> その場合はこの方法が使えないので、**当日ではなく事前に**分かるようにしてください。

---

## 当日の手順

### ① データを新しくする(出発前・店で)
1. 店のPCで **`バックアップ.bat`** を実行(必ず先に)
2. 店のPCの **`db\tokiwa.db`** を、Macの **`db/tokiwa.db`** に**上書きコピー**

> これで「その朝までの顧客・購入履歴・処方箋」を持って出られます。

### ② 会場で起動する
1. **iPhoneのインターネット共有をON**にする
2. **Macをそのテザリングにつなぐ**
3. Macで **`ツール/Mac用/店外イベントで起動.command`** をダブルクリック

黒い画面にURLが出ます:

```
 スマホ・iPad からは次のURLで開きます:
   http://172.20.10.3:8760/    (en0)
```

> 初回だけ「開発元が未確認」と出ることがあります。
> その時は **Finderでそのファイルを右クリック →「開く」→「開く」** で一度許可すれば、
> 次からはダブルクリックで開きます。

### ③ スマホ・iPadから開く
1. **スマホをMacと同じテザリングにつなぐ**
2. Safari のアドレス欄に **上のURLをそのまま入力**
3. ログイン画面が出たら、自分のユーザーでログイン

> **繋がらない時**: 画面に出たURLを上から順に試してください。
> それでもダメなら、**Macとスマホが同じWi-Fiか**をもう一度確認します
> (スマホが4G/5Gのままだとつながりません)。

### ④ ホーム画面に追加しておく(おすすめ)
Safariの共有ボタン →「ホーム画面に追加」。次から一発で開けます。
**ただしURLはWi-Fiが変わると変わります**ので、次のイベントでは入れ直してください。

### ⑤ イベント中にできること
| できる | できない |
|---|---|
| 顧客を探す(カナ・電話・ローマ字) | **会計(レジ)** ← 打たない約束 |
| 購入履歴を見る | レシート印字・ドロワー |
| メガネ処方箋・度数を見る | ポイントカードの読取・書込 |
| 売掛残高・ポイント残高を見る | スマホのカメラでバーコードを読む |
| 顧客メモ・家族を見る | |

### ⑥ 売れたら紙に控える
あとで打ち直すために、**この5つ**を控えてください。

- **お客様のお名前**(同姓が居るので、分かれば電話番号か顧客IDも)
- **商品番号**(在庫品の場合)/ 品名(番号なしの場合)
- **買上金額**(値引き後の実際にいただいた金額)
- **支払方法**(現金 / カード / PayPay / 掛売 / 分割)
- **会計担当**

### ⑦ 終わったら止める
黒い画面で **Control+C**。Macを閉じて終わりです。

## 帰ってからやること(店で)

1. **Macで打ったものは何もありません**(見るだけなので、Macのデータは触っていません)
2. 本番機でトキワを開き、**レジ画面 → ③商品の右端「過去の日付で登録する」にチェック**
3. **売上日をイベント当日**にする(⚠と売上日の帯が出ます)
4. 控えた内容を**1件ずつ普通に会計する**
5. 全部打ち終わったら、**チェックを外す**(または「今日に戻す」を押す)

> ⚠ **過去日のまま次のお客様を打たないこと。**チェックが入っている間は
> 画面の上に警告の帯が出続けます。必ず外してください。
>
> ※過去の日付で登録した会計では、**レシートもドロワーも出ません**(当日以外は出さない作り)。
> イベントのお客様には会場で手書きの領収書をお渡しし、必要なら後日レシートを郵送します。

### Macのデータはどうするか
**イベントが終わったら、Macの `db/tokiwa.db` は消してください。**
次のイベントの時に、また店から新しいものをコピーします。

> 古いデータを残しておくと、次のイベントで**何ヶ月も前の残高**を見てお客様に
> 伝えてしまいます(ポイント残高・売掛残高は毎日変わります)。

---

## なぜイベント中に会計を打たないのか

トキワのデータは **`db/tokiwa.db` という1つのファイル**です。

Macで会計を打つと、
- **店のDB**には店頭の売上が入り、
- **MacのDB**にはイベントの売上が入ります。

**この2つを後から合体させる仕組みはありません。**どちらか一方を選ぶしかなく、
選ばなかった方の売上は消えます。「見るだけ」にしておけば、**Macのデータは
最初から読むだけ**なので、この事故が起きません。

> イベント中も店を閉めているなら、Macで会計を打って帰りにMacのDBを店へ戻す
> やり方(案B)も成り立ちます。ただし**店で1件でも打ってしまうと戻せない**ので、
> 今回は案Aにしています。

## 個人情報の持ち出しについて(必ず読んでください)

Macに入れるのは**お客様25,000人分の名簿と購入履歴**です。落とした・盗られた時の
影響が、普通のノートPCの紛失とはまったく違います。

- **FileVault(ディスク暗号化)を必ずONにする**(システム設定 → プライバシーとセキュリティ)
- **Macのログインパスワードを設定する**(自動ログインはOFF)
- **会場の公共Wi-Fiにはつながない。**同じWi-Fiの他人からも `:8760` が見えます。
  **自分のテザリングを使ってください**
- **イベントが終わったら `db/tokiwa.db` を消す**(上記)

## 困った時

| 症状 | 見るところ |
|---|---|
| スマホから開けない | Macとスマホが**同じWi-Fi**か / 画面に出た**別のURL**を試す |
| 途中で切れた | **Macがスリープしていないか**(起動の .command はスリープを止めますが、フタを閉じると止まります) |
| 「既に起動しています」と出る | 前の黒い画面が残っています。そちらで Control+C |
| python3 が無いと言われる | ターミナルで `xcode-select --install` |
| 起動が「db/tokiwa.db がありません」で止まる | 店のDBをコピーし忘れています(①へ) |
