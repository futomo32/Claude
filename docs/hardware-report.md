- **確認方法**: 本番機上のClaude Codeで読み取りのみ実施(設定変更なし)

|---|---|---|---|---|
| スター精密 | SMJ USB Device(TCP300IIシリーズ/店内呼称「TCP342」) | `VID_0519` / `PID_0002` | COM3(仮想COM) | OK / 稼働中 |
| CITIZEN | Virtual Communication Port(CT-S601) | `VID_1D90` / `PID_0FFF` | COM7(仮想COM) | OK / 稼働中 |

### TCP300II モデル判定

- バス報告名: `TCP300II (STR-U100)`。USB情報からはシリーズ名までしか判別不可
- 「TCP342II/TCP352II」という型番は公式には存在しない。実在の正式型番は
  **TCP300II(磁気1トラック・JIS II)** / **TCP310II(磁気3トラック・ISO)** の2種
- 正式型番の確定は本体底面/背面ラベルの目視で行う(未実施)

  仮想COMポート(COM3)へ**直接シリアル通信**している構成

## 結論(トキワ開発への影響)

1. **Windows 11 Pro(26200)上で両機器のドライバーが現に稼働** —
   「TCP300IIはWin11非対応」という懸念は本番機では既にクリアされている
2. **OCX不要と判明したため、トキワからの制御は想定より簡単** —
   仮想COMへのシリアル通信は現代の開発環境(Node/.NET等)から標準的に扱える。
   中継プログラムの想定が不要になり、TCP300IIのコマンド仕様書だけあればよい
3. CT-S601も仮想COM+標準ドライバー構成で、ESC/POS制御・ドロワーキックとも通常どおり可能
