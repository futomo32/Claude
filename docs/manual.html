第1部　簡潔版(クイックスタート)

よく使う操作を手順だけまとめました。細かい説明は第2部を見てください。

1. ログインと画面の見かた

  • 自分のユーザーでログインします。初回はパスワードを設定します。
  • 左のメニューで画面を切り替えます:
    ￥ レジ👤 顧客管理🔍 検索・分析💳 売掛管理◆ 商品・在庫📋 棚卸し🔧 修理伝票📄 見積・請求▤ 日報・帳票⚙ 設定・マスター
  • 権限がパートの人は、原価(下代)・粗利・符丁・商品在庫画面・設定は見えません。

2. レジで会計する

  1. お客様を選ぶ … カタカナ名や電話番号で検索。新規なら「＋新規顧客」。
  2. 商品を明細に足す … 「＋商品番号で追加(在庫品)」でスキャン/番号入力。修理・電池などは「＋番号なしで追加」。
  3. 金額を確認 … 値引きは買上金額をその場で書き換えればOK。
  4. 会計担当を選ぶ … レジを打つ人を毎回選びます。
  5. 支払方法を選ぶ … 現金/クレジット/PayPay/掛売/分割。分割払いは「＋支払方法を追加」。
  6. お預かりを入れて「会計を確定」 … 釣銭が出ます。確定で購入履歴・在庫引落・(掛売なら)売掛計上まで自動。
掛売にすると、その分がお客様の売掛残になります。現金は入っていないので、その日の現金締めには数えません。

3. 顧客を探す・新しく登録する

  • 探す: 「👤 顧客管理」でカナ・電話番号・担当者・ランク・誕生月から検索(半角/全角・大小文字は気にしなくてOK)。
  • 詳細: 顧客を開くと、基本情報／購入・アプローチ履歴／入金管理／ポイント／メガネ処方箋のタブがあります。
  • 新規登録: 「＋新規顧客」。郵便番号から住所を呼び出せます。
  • 家族: 基本情報から家族を追加・修正・削除できます。

4. 売掛の入金を記録する

  1. 「💳 売掛管理」で対象のお客様を開く(残高の多い順に並びます)。
  2. 「入金」で入金額と方法(現金/銀行振込/カード/その他)を入れる。
  3. 残高が自動で減り、入金履歴に1行残ります。
訂正・削除: 入力ミスは「修正」で残高を直す、または「削除」。過去の紙の売掛は「＋売掛を追加」で手入力できます。

5. 商品を登録する(符丁は自動)

  1. 「◆ 商品・在庫」→「仕入登録」タブ。
  2. 品名・分類・仕入先・仕入単価(下代)・上代などを入力。
  3. 符丁は、仕入先と仕入単価を入れると自動で入ります(手直しも可)。
  4. 「登録」で在庫に入ります。写真も付けられます。
符丁の頭文字(メーカー)は、先に「設定・マスター → 仕入先マスタ」で符丁文字を1回登録しておくと自動で付きます。

6. 催事で受託品を打つ

  1. レジで「＋受託品(催事)」を押す。
  2. メーカー(仕入先)を選び、金額を入れる(品名は任意)。
  3. 明細に載るので、そのまま会計。原価・正式品番は後日、納品書が来てから入れます。

7. 修理を預かる

  1. 「🔧 修理伝票」→「＋新規預かり」。
  2. お客様・品物・内容を入力。写真も撮って添付できます。
  3. 預かり伝票を印刷してお渡し。進行状況(未引渡/引渡済み)で管理します。

8. 棚卸しをする

  1. 「📋 棚卸し」を開く(開始日時が記録されます)。
  2. 現物を1点ずつ商品番号でスキャン/入力して「確認」。
  3. 最後まで「未確認」に残った在庫が差異(紛失・登録漏れの疑い)。CSVに出せます。
  4. やり直すときは「最初からやり直す」。

第2部　詳細版(画面ごとの説明)

9. 全体像・ログイン・権限

トキワは、宝飾ナビに代わる店舗の販売・顧客・在庫の管理システムです。1台のPCで動かし、ブラウザで使います。

ログイン

  • ユーザーごとにログインします。パスワードは本人が初回ログイン時に設定します(管理者がリセットすると、次回ログインで再設定)。

権限(役割)

役割できること
管理者すべて可(ユーザー管理・担当者マスタを含む)。
社員ユーザー管理・担当者マスタ以外はほぼ可。
パート原価(下代)・粗利・符丁・商品在庫画面・設定は見えません。レジ・接客まわりが中心。
符丁・原価の保護: 符丁は下代そのものを表すため、パート権限には送られません(画面にも出ません)。

10. レジ(売上登録)

お客様を選び、明細を作り、支払を確定する画面です。

明細の作り方

  • ＋商品番号で追加(在庫品): 在庫の商品を番号で追加。スキャナまたは手入力。
  • ＋番号なしで追加: 電池交換・レンズ・各種修理など、在庫品でないものを品名・金額で追加。
  • ＋受託品(催事): メーカーの受託品をその場で追加(→ 22章)。
  • 💴 レジ入出金: 代引手数料・収入印紙・両替・経費など、買い物と無関係な現金の出入り。

金額・値引き

各明細の買上金額は書き換え可能です。値引きはここで金額を下げて表現します。定価との差から割引率が表示されます。

お会計

  • 会計担当: レジを打つ人を毎回選びます(打ち手の意識づけのため、毎回リセットされます)。
  • 支払方法: 現金 / クレジット / PayPay / 掛売 / 分割。「＋支払方法を追加」で分割払い(複数方法)に対応。
  • 掛売: 選ぶとその金額が売掛残になります。現金締めには数えません。
  • 使用ポイント: 会計でポイントを使う枠があります。
  • お預かり・釣銭: 現金分のお預かりを入れると釣銭が出ます。テンキーで入力できます。
  • 会計を確定: 購入履歴へ記録、在庫品は在庫から引落、掛売は売掛へ計上——までを自動で行います。

11. 顧客管理

検索

顧客名・カナ・電話番号・担当者(番号でも可)・ランク・誕生月で絞り込めます。カナ検索は半角/全角・大小文字を自動でそろえて照合します。

顧客詳細(タブ)

タブ内容
基本情報住所・連絡先・担当・ランク・家族など。編集や家族の追加/修正/削除。
購入・アプローチ履歴買上の履歴と、お声がけ(来店/DM/TEL/手紙)の記録。
入金管理そのお客様の売掛と入金の状況。
ポイントポイントの残高・加算/使用の履歴。
メガネ処方箋度数などの処方箋情報。

新規登録

「＋新規顧客」から登録。郵便番号→住所の呼び出しに対応。

12. 検索・分析

タブ内容
詳細検索顧客の属性 × 買った商品 × 処方箋を掛け合わせ(AND)で絞り込む横断検索。「同一商品を買った人」「特定条件の人」を抽出。
購入順位ランキング買上金額などの順位付け。
メガネ処方箋検索処方箋の条件で顧客を探す。

13. 売掛管理

売掛(未回収残高)のあるお客様を、残高の多い順に一覧します。誰がいくら・件数・最古買上日・最終入金日が見えます。

  • 入金: 入金額と方法(現金/銀行振込/カード/その他)を記録。残高が減り、履歴に残ります。
  • ＋売掛を追加: レジを通さない過去分(紙の売掛)を手入力。
  • 修正 / 削除: 入力ミスの訂正用。
今後の予定: 売掛を立てた「後から」の値引き・ポイント使用は、専用の操作として追加予定です(現金入金とは区別して扱います)。

14. 商品・在庫(仕入登録・符丁)

在庫一覧

状態(在庫/売上/受託/返品)・仕入先・ジャンル(宝石/メガネ/時計/その他)で絞り込み。商品を開くと詳細・写真が見られ、修正できます。

在庫数は「状態＝在庫」の商品だけを数えます。売れた品・受託品は在庫数に混ざりません。

仕入登録

  • 品名・分類・ブランド・地金・仕入先・仕入単価(下代)・上代・店舗などを入力。宝石以外は宝飾専用の項目が隠れます。
  • 掛率・折数は自動計算。
  • 符丁は仕入先と仕入単価から自動入力(→ 21章)。手直しも可。
  • 商品写真をその場で撮る/選ぶことができます。

15. 棚卸し

店頭・金庫の現物を1点ずつ「商品番号」で読み取り、在庫台帳と照合します。

  • 開始日時が記録されます。
  • スキャン/入力→「確認」で現物確認済みに。緑=確認、赤=注意(番号なし/売却済み)、既に確認済みの再スキャンはお知らせのみ。
  • 同じ番号の在庫が複数あるときは、スキャンのたびに1点ずつ確認します。
  • 最後まで「未確認」に残った在庫が差異(紛失・盗難・登録漏れの疑い)。CSV出力できます。
  • 「最初からやり直す」で確認記録をリセット。
棚卸しはパート権限では使えません。

16. 修理伝票

宝飾ナビには無かった新機能。お預かりした修理品を管理します。

  • 「＋新規預かり」でお客様・品物・内容・見込みなどを登録。
  • 写真を撮って添付(お預かり品の状態記録)。
  • 預かり伝票を印刷してお渡し。
  • 状態(進行中/引渡済み)で絞り込み・管理。

17. 見積・請求

品名・金額の明細を作り、見積書・請求書として出力します。在庫商品から明細に取り込むこともできます。

18. 日報・帳票

  • 日報: その日の売上・現金の締め。現金と、振込・カードなど非現金を分けて確認できます。掛売(未回収)は現金に数えません。
  • 売上伝票明細表: 期間・担当などで売上明細を一覧。

19. 設定・マスター

マスタ管理

担当者・仕入先・商品分類・ブランド・石種・地金・購入動機・保管場所・支払方法・顧客ランク・地区を1画面で管理します。

  • 仕入先マスタ: ジャンル(宝石/メガネ/時計/その他)と、符丁文字(メーカーの頭カナ)を登録。符丁文字を入れておくと、商品登録時に符丁の1文字目が自動で入ります(漢字名のメーカーでもOK)。

ログインユーザーと権限(管理者のみ)

ユーザーの追加、役割(管理者/社員/パート)の設定、パスワードのリセット。

20. 符丁の仕組み

符丁は、下代(仕入値)を店内だけで読める形に隠した符牒です。トキワは下代の上3桁を、下の表でカナに置き換えます。

数字1234567890
カナｴﾋｽｱｷﾅｲｶﾐｹ
  • 1文字目はメーカー(仕入先マスタの符丁文字)。
  • 同じ数字が連続したら、先頭1文字＋「ﾀ」1つにまとめます。

例(頭文字ｳ): 下代30800 → 上3桁308 → ｳｽｹｶ ／ 下代12200 → 上3桁122 → ｳｴﾋﾀ ／ 下代10000 → 100 → ｳｴｹﾀ

符丁は原価が分かってしまうため、パート権限には表示されません。

21. 受託(催事)の運用

催事などで、メーカーの品(自店の在庫でない品)をその場でレジに通すための機能です。売上が先・納品書は後という流れに合わせています。

使い方(A方式)

  1. レジで「＋受託品(催事)」を押す。
  2. メーカー(仕入先)を選び、金額を入れる(品名は任意=既定「受託品」)。
  3. 明細に載るので、通常どおり会計。会計すると売上になります。
  • 受託品は在庫数には数えません(自店の持ち物でないため)。
  • 原価・正式品番は、後日メーカーの納品書が届いてから入れます(後日精算=Phase 2で対応予定)。

22. メンテナンス(バックアップ等)

バックアップ

データはPC内のデータベース1ファイルにまとまっています。定期的にバックアップを取ってください(火災・故障・盗難に備え、店外にも複製が理想)。

python3 scripts/backup_db.py(タイムスタンプ付きで複製)

売掛のクリア(初期化)

  • python3 scripts/clear_receivables.py … 売掛残高のみ消去(入金履歴は残す)。実行前に自動バックアップ。
  • --with-history … 入金履歴も消す。 --yes … 確認省略。
  • 再取込で復活します。恒久的に空で始めるなら取込時に import_csv.py --no-receivables。
注意: スクリプトはサーバーを止めてから実行してください。復元はバックアップファイルを db/tokiwa.db に戻します。
