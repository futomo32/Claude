# トキワ 受け入れテスト チェックリスト

一通り機能が仕上がった後に、実機で上から順に潰していくための簡易チェックリスト。
新しい機能を実装したら、その都度この表に行を追加していく(「生きたチェックリスト」)。

- 運用で触る順に並べてある。
- ★印は依存機能(B-7 商品画像など)が仕上がってから厚めに確認する項目。
- 最終更新: 2026-07-22

---

## 0. 起動・ログイン
- [ ] サーバー起動(`python3 server/app.py`)→ ブラウザで開くとログイン画面が出る
- [ ] 管理者/社員/パートでそれぞれログインできる(初回はパスワード設定)
- [ ] パート＝「在庫」「設定・マスター」が消え、仕入額(下代)・粗利が見えない
- [ ] ログアウト→再度ログイン画面に戻る

## 1. 顧客
- [ ] 顧客検索(名前・カナ・電話・住所・ID)で目的の顧客が出る
- [ ] 顧客一覧の累計購入額・当年度でソート(▲▼)が効く
- [ ] 新規顧客を登録→一覧・検索に出る
- [ ] 顧客情報を編集→保存が反映される
- [ ] 生年月日の和暦/西暦トグル、家族の追加(新規／既存客リンク)

## 2. レジ(会計)
- [ ] 在庫番号ありの商品を追加できる／番号なしで追加できる
- [ ] メガネ選択→処方箋で品名を直すと購入一覧にも反映される
- [ ] お預かり金入力→釣り計算→会計確定→DBに残る
- [ ] 売掛残高のある顧客はレジで入金を受けられる
- [ ] 他画面へ移動してもレジ入力が保持される

## 3. 売掛・入金
- [ ] 左メニュー「売掛管理」で合計金額・担当別一覧・件数が出る／CSV出力
- [ ] 顧客詳細「入金管理」で売掛明細が買上日降順、ヘッダで昇順/降順切替
- [ ] 売掛の追加・修正・削除が明細と残高タイルに反映される
- [ ] 入金する→残高が減り入金履歴に記録される
- [ ] 請求書を印刷(プレビュー→印刷)

## 4. 商品・在庫 ★B-7完成後に厚めに
- [ ] 在庫一覧が商品番号の降順、絞り込み(分類・状態・仕入先)が効く
- [ ] 商品登録(宝石／宝石以外タブ)→確認→修正→削除
- [ ] 写真の登録・差し替え・削除(削除で画像ファイルも消える)
- [ ] 商品詳細・レジ・購入履歴で写真が見える／購入履歴から商品詳細へ飛べる
- [ ] 掛率・折数の計算が正しい(税込換算)

## 5. 検索・分析
- [ ] 誕生日検索・ランク検索・購入ランキング・メガネ処方箋検索
- [ ] 「ななし(集計対象外)」がランキング等から除外され、日次売上には含まれる
- [ ] 検索結果→チェック→住所ラベル印刷

## 6. 顧客ランク更新
- [ ] プレビューでランク別人数分布(現在/再計算後/増減)が出る
- [ ] 最下位ランク9の据え置き、チェックONで復活
- [ ] 期間指定(いつから〜いつまで)で集計が変わる／逆期間はエラー
- [ ] ランク基準の編集・保存

## 7. 帳票・日報
- [ ] 日報照会(デフォルト日付＝当日)、売上四分類(催事/店頭/メガネ/時計)
- [ ] 見積書・請求書・修理伝票の印刷(発行元「宝石・メガネ・時計 ヤナセ」)

## 8. 返品・監査
- [ ] レジ/購入履歴から返品(取消)→各集計から除外、在庫に戻る
- [ ] 「取消済みも表示」トグルでログが見える

## 9. マスタ・ユーザー管理
- [ ] 各種マスタ(担当者・仕入先・分類・ブランド等)の閲覧・編集、戻るボタン
- [ ] 管理者のみユーザーの追加・役割変更・パスワードリセット

## 10. データ整合・締め
- [ ] ホームのタイルが当日データ、日跨ぎで自動更新
- [ ] 実データ再取込(import_csv.py)後も表示崩れなし
- [ ] バックアップ(db/tokiwa.db)の退避
